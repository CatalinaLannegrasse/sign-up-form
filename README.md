# Sign-up Form - The Odin Project

A responsive two-column sign-up page built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. This project focuses on modern HTML5 form validation, CSS Flexbox layouts, custom web fonts, and clean UI design.

## Built With

* **HTML5**: Semantic structure and native form validation attributes (`minlength`, `pattern`, `required`).
* **CSS3**: Flexbox layouts, custom properties, and pseudo-classes (`:focus`, `:user-invalid`).
* **Custom Typography**: Custom `@font-face` integration for the Norse logo font.

## Features

* **Two-Column Split Layout**: Full-height decorative background image on the left with a dark, semi-transparent logo banner, and a clean structured form on the right.
* **Advanced HTML5 Form Validation**: 
  * Email syntax checking.
  * Custom regular expression pattern matching for phone numbers.
  * Minimum character requirements for passwords.
* **Interactive States**: Dynamic `:focus` styles with subtle box-shadows and real-time `:user-invalid` error borders.
* **Password Helper Text**: Inline guidance for users detailing password requirements.

## What I Learned

* Structuring a complex page layout using **CSS Flexbox** without relying on advanced grid systems.
* Implementing native browser form validation and pseudo-classes like `:user-invalid` to handle user input errors smoothly without JavaScript.
* Organizing custom web assets like `@font-face` and handling background overlay positioning.
